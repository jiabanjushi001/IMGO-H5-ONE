# 兼容与迁移检查

## 路径

`legacy-routes.json` 列出从 PHP 控制器和编译前端提取的路径，自动化测试逐一检查路由注册。没有重命名业务路径。`/manage/User/index`、`/enterprise/im/editpassword`、`/enterprise/group/groupuserlist` 等大小写混用均可访问。

请求支持 JSON、表单、multipart 及 PHP/qs 的 `setting[x]`、`user_ids[0]`、`messages[0][id]` 形式；沿用 Bearer Authorization。

控制器内部帮助方法不对外注册：`doBindUid`、`uploadLocalAvatar`、`getVideoCover` 等。网页安装器保留路径并明确返回 410，使用 CLI 初始化/迁移。

## 数据库

`-migrate` 会：

- 将 `user.password` 扩为 VARCHAR(255)，用户表设为 DYNAMIC 行格式，兼容旧库的组合索引。
- 将登录 IP、注册 IP 字段扩为 VARCHAR(45)。
- 增加 `imgo_session`（持久会话）、`imgo_chat_lock`（会话内写入序列化）及 `imgo_object`（云对象定位）三张表，使用现有表前缀。
- 增加消息、群成员、好友、文件和表情查询索引。
- 补上缺少的基础配置，已有配置不覆盖。
- 为旧语音消息及用户头像中缺失的文件记录补建元数据，语音消息关联 `file_id`，以兼容鉴权下载。不会从远端下载文件。此步骤需要正确的旧 CHAT_KEY。

迁移显式执行，不在普通启动中自动执行。MySQL DDL 无法整体事务回滚，中途失败需按报错修复后重试；大库加索引应安排维护窗口。`-init` 检测到已有用户表会拒绝初始化。

普通启动会自动补齐 Go 扩展表和兼容字段。本版本会创建 `imgo_admin_role`、`imgo_admin_permission`、`imgo_admin_role_permission`，为 `user` 增加 `admin_role_id`，并写入后台菜单权限目录。已有用户默认保持普通用户身份；初始超级管理员 `user_id=1` 始终拥有全部权限。

## 登录失效返回兼容

与原 PHP `CheckAuth` 一致：缺少/无效/过期 token、会话已撤销、账号已禁用时，业务 API 返回 HTTP 200，JSON `code: -1`、非空 `msg` 和 `data: []`。uniapp 的成功回调据此跳转登录页；错误回调中的 401 仅对应 HTTP 状态码。权限不足仍是业务码 403；媒体资源未登录仍返回 HTTP 401。

## 安全与行为变化

- 不接受客户端伪造发送人；HTTP 和 WebSocket 都验证登录会话。
- 群成员、群角色、消息参与者、附件读取权限都在服务端检查。
- 普通用户只使用聊天功能。超级管理员可创建后台角色，为每个角色配置菜单权限，并给每个用户分配一个角色；菜单对应的后端接口同步校验权限。角色管理、角色授予及高风险系统操作仍限初始管理员 `user_id=1`。
- 附件 URL 不再是匿名访问凭据。浏览器使用登录时设置的 HttpOnly cookie；其他客户端使用 Authorization。
- 同源部署能保持图片等浏览器资源加载方式。跨域客户端应专门联调 Cookie、域名和媒体鉴权，不能假设原匿名下载方式仍可用。
- 群二维码使用新签名，旧群二维码须重新生成；用户二维码 Hashids 兼容原盐值。
- 上传拒绝执行文件和可执行网页内容；富文本消息在存储/展示时消毒。
- Go 不调用用户输入拼接的 shell 命令、不提供远程下载后写文件接口。
- 默认关闭后台清理。在后台首页“Go 定时清理”面板设置执行间隔（1–43200 分钟）与保留天数（1–3650 天），点击“保存并开启”。设置保存在 config.maintenance，优先于 MAINTENANCE_ENABLED；重启后保留。首次执行在一个间隔后，系统每 10 秒检查到期任务。清理沿用 chatInfo.msgClear/msgClearDay，隐藏过期消息，保留系统公告及实体附件；停止不影响 HTTP/WebSocket。日志保留最近 20 次。
- 密码、验证码、SSO token 和客户端连接不沿用原服务内存状态。切换后客户端需重新登录。

## 本轮补齐与验证边界

| 功能 | 实现与验证 |
| --- | --- |
| 七牛 Kodo、阿里云 OSS、腾讯云 COS | 官方 Go SDK 上传、鉴权后短期签名下载；旧云对象路径兼容。离线签名测试通过，未使用真实云凭据联调 |
| 短信 | 兼容旧 aliyun/qcloud/ucloud/qiniu/upyun/huawei 配置与验证码模板；请求构造测试通过，未真实发送 |
| 内容审核 | ThinkAPI green/text 适配，THINKAPI_TOKEN 启用；模拟通过/拦截/故障测试。供应商异常时拒绝提交 |
| 自动客服 / 自动建群入群 | 事务执行、客服轮询、加密欢迎消息、群满新建、失败回滚；真实 MySQL 验证 |
| 视频封面 | FFMPEG_BIN/FFPROBE_BIN 可选适配，限制协议、超时、直接参数调用；本机尚未安装 FFmpeg，未验证真实视频抽帧 |
| 群头像 | 合成最多 9 个成员头像，受群成员权限控制；HTTP PNG 尺寸/状态码测试通过。云头像暂以姓名首字替代 |
| 中文拼音 / IP 属地 | Go 拼音；兼容原项目 IP 数据库。附带数据版本为 2016060110，属地仅反映该旧库，IPv6 暂返回空 |
| 加密消息搜索 | 在已授权会话范围分批解密、过滤、分页，不创建明文索引；真实数据库测试通过。大历史库搜索成本高，30 秒超时 |
| 消息事件 | contactInfo、role、toUser、@所有人、已读 @、上下线通知补齐 |
| WebRTC | 调整呼叫/挂断/多端信令和历史时长；HTTP 及数据库回归通过，TURN、摄像头、双设备通话尚未联调 |
| 表情 | 可收藏有读取权限的图片，重复收藏复用记录，删除后可恢复；真实数据库测试通过 |
| 多实例 | 仍使用单进程 Hub、限流及验证码缓存，不支持直接多副本负载均衡 |

路径测试检查注册覆盖，不代表每个客户端页面和全部参数组合已逐项验收。第三方真实账号、邮件和客户端安装包未配置；不能把适配器测试等同于真实服务可用。配置示例见 PROVIDERS.md。

## 生产切换

本项目只在本机创建独立 `imgo` 数据库和测试库，没有连接或修改服务器。此前已部署的 PHP 文件、计划任务和系统进程不会因创建此项目而自动清理。

迁移前需确认旧服务器文件和数据库备份可信，轮换可能暴露的密钥；保留旧 CHAT_KEY 是为读取历史记录，不要公开它。生产配置使用独立数据库账号，禁止使用本机开发 root 密码。
