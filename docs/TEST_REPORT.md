## 测试中发现并修复

1. 旧 user 表 COMPACT 行格式与扩长后的密码组合索引冲突：迁移改为 DYNAMIC。
2. macOS `/var` 符号链接路径与真实路径比较导致附件误拒绝：先规范化根目录后验证。
3. `INSERT IGNORE` 加 `SELECT FOR UPDATE` 造成并发锁升级死锁：改为独占写锁后序列化聊天事务，再执行消息幂等检查。

4. 群头像查询漏参数及 Gin NoRoute 默认 404：补齐参数并显式输出 200。
